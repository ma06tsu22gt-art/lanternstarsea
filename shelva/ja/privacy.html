SHELVA プライバシーポリシー

制定日: 2026年11月22日

STEAM BASE（以下「当社」）は、ゲーム「SHELVA」（以下「本アプリ」）における利用者の情報の取り扱いについて、次のとおり定めます。

1. 当社が集める情報

本アプリには氏名やメールアドレスを入れる会員登録はなく、当社が利用者の氏名・電話番号・住所などを集めることはありません。

本アプリを始めると、端末ごとにプレイヤー ID が作られます。ゲームのデータ（持ち物・進み具合・購入の記録・リーグとボス戦の編成と成績・購入の上限のための年齢の区分）は、このプレイヤー ID とひもづけて、当社が使うサーバー（Unity Gaming Services）に保存されます。

設定の「引き継ぎ」を使ったときは、Google Play ゲームのプレイヤーの識別子も、プレイヤー ID とひもづけて保存します。設定の「引き継ぎ」で ID とパスワードを出したときは、その ID とパスワードを、引き継ぎのために当社のサーバーに保存します。

お問い合わせのメールをいただいたときは、メールアドレスとメールの内容を返信のためだけに使います。

3. ほかの利用者に表示される情報

リーグの対戦相手の候補として、あなたの守りの編成・戦力・ランクが、ほかの利用者に表示されます。ボス戦とリーグの順位にも、あなたの成績が表示されます。順位と守りの記録には、あなたのプレイヤー名（始めたときに自動で付く名前で、設定の画面で変えられます）も表示されます。本名や連絡先は表示しません。

4. 広告IDと同意

広告IDは、端末の設定でいつでもリセットしたり、パーソナライズされた広告を止めたりできます。アプリ内で「広告なし」を購入すると、全面広告は表示しません（報酬がもらえる広告は、利用者が選んだときだけ表示します）。

欧州経済領域（EEA）・英国・スイスでは、最初に同意を確かめ、同意をいただいたときだけパーソナライズされた広告と分析のための記録を行います。同意は設定の画面からいつでも変えられます。

5. 情報の使い道

当社は、集めた情報を、本アプリの提供（データの保存・購入の処理・順位の表示）、不正の防止、運営と改善のためにだけ使います。法令にもとづく場合を除き、利用者の個人情報を第三者に提供することはありません。

6. お子さまの利用

本アプリは13歳未満のお子さまを対象としていません。13歳未満のお子さまの情報を当社が意図して集めることはありません。

7. 安全のための取り組み

サーバーや外部サービスとの通信は暗号化（HTTPS）されています。

8. 保存の期間と削除

サーバーのデータは、アカウントを削除するまで保存します。設定の「アカウントの削除」を使うと、サーバーのデータを削除します。ただし、リーグとボス戦のランキングに載った名前と点は、次の週の締め（毎週月曜 0:00 日本時間）まで残り、そのあと消えます。本アプリを消したあとでも、データの削除のページの方法でメールから削除を頼めます。分析の記録やお問い合わせのメールの削除を希望するときも、下のメールアドレスにご連絡ください。外部サービスが持つ情報は、各事業者のポリシーに従って削除を求めることができます。

9. このポリシーの変更

内容を変えるときは、このページで知らせます。
